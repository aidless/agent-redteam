# Demo asset provenance

- `demo.gif` / `demo.png`: rendered 2026-10-25 from a curated view of the real
  `python3 demo/cli.py` stdout in `demo.txt` (rc=0, 155 ms).
- `demo.txt`: raw stdout of that run.
- Attack payloads are synthetic (`data/attack_vectors.json`); the defense
  actions are produced by the real classes in `defenses/`. No API calls.
